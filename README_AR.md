# Explode Arena — المشروع الرئيسي (0.21 Alpha)

هذه **شجرة المصدر الرئيسية الوحيدة** لعمل Faithful Remaster للعبة Symbian على Android. نطوّر نفس المشروع بدل إنشاء Prototype منفصل مع كل تحديث.

## المنجز القابل للتشغيل

- جميع الساحات الـ41 بمعاينات خرائط مأخوذة من الموارد الأصلية. ترتيب الطبقات والشفافية والألوان يحتاج مطابقة نهائية مع تشغيل Symbian.
- 32 إطارًا أصليًا للشخصية موزعة على أربعة اتجاهات، و42 إطارًا أصليًا للانفجارات من NPS، و15 مؤثرًا صوتيًا WAV مع ملف MOD الأصلي ومعاينة MP3 له.
- منطق لعب بتحديث ثابت 60Hz ومحاكاة قابلة لإعادة الإنتاج بمدخلات عشوائية ذات بذرة ثابتة.
- الحركة والقنابل والانفجارات المتسلسلة وفترة الحصانة وخصم تجريبي قادر على ملاحقة اللاعب عبر مسارات الخريطة وزرع قنابل؛ **الميكانيكيات لا تزال مؤقتة وغير مطابقة للأصل بعد**.
- **لعب محلي تجريبي لشخصين** داخل نفس الساحة: لكل لاعب حركة وقنابل وصحة وحالات فوز وتعادل، مع واجهة لمس مستقلة لكل لاعب. هذا ليس تنفيذًا مثبتًا لوضع Bluetooth الموجود بالأصل.
- قائمة ساحات، إيقاف واستئناف، إعادة اللعب، تفضيلات محلية، زر تشغيل موسيقى اختياري، وملف HTML مكتمل يعمل دون اتصال.

## التحكم

| الوضع | اللاعب الأول | اللاعب الثاني |
|---|---|---|
| لاعب واحد | الأسهم أو WASD + Space | — |
| لعب محلي | الأسهم + Space | WASD + F |
| لمس | الأسهم وزر القنبلة الأول | لوحة اللمس الثانية وزر P2 BOMB |
| أيدي التحكم | يد تحكم أولى | يد تحكم ثانية |

على هاتف صغير تظهر لوحتا اللمس بالتتابع، وعلى التابلت يمكن التجربة باللمس أو بيدَي تحكم. لم تُختبر الأجهزة الفعلية بعد.

## تشغيل وتجربة المصدر

- جرّب `Explode_Arena_Offline.html` مباشرة في متصفح يدعم ملفات HTML المحلية؛ لا يحتاج إنترنت.
- تطوير ويب: من `web/` شغّل `python -m http.server 8000` وافتح `http://localhost:8000`.
- مشروع Android موجود تحت `android/`، وكل موارد اللعبة ضمن `android/app/src/main/assets/` بعد تشغيل `python tools/sync_android.py`.
- التحديث الحالي 0.21 Alpha. تم بناء **Debug APK حقيقي** عبر GitHub Actions داخل المستودع الخاص، والتحقق من بنيته وتوقيعه وبصمته. لم يُختبر على جهاز Android فعلي بعد.

## بناء APK في مستودع GitHub خاص

1. المشروع محفوظ في مستودع **Private**؛ أبقه خاصًا بسبب الأصول الأصلية وحقوق أصحابها.
2. افتح Actions واختر `Build private Android debug APK` ثم `Run workflow`، أو ادفع تعديلًا إلى `main`.
3. سيحاول Workflow تنزيل SDK 35 وأدوات البناء، وتشغيل اختبارات المحرك، ثم بناء `:app:assembleDebug`.
4. يظهر APK في Artifacts باسم `ExplodeArena-private-debug-apk` مع ملف SHA-256 وتقرير بصمة شهادة التوقيع. تم التحقق من هذا المسار فعليًا بتاريخ 2026-10-18.

## القيود الأساسية

- لم نتأكد بعد من سرعة الشخصية، توقيت قنابل الأصل، نظام التصادم النهائي، AI، جميع الـPower-ups، أو أوضاع اللعبة الأصلية.
- طور الشخصين المحلي للتجربة؛ ليس استعادة كاملة لـBluetooth Multiplayer.
- إعادة الإتقان HD للرسومات والصوت لم تبدأ بعد؛ الأصول الحالية من الاستخراج الأصلي، والرسومات المعروضة معاينات.
- المصدر يجب أن يبقى في GitHub خاص، وأصول اللعبة الأصلية محمية بحقوق أصحابها؛ لا نشر عام دون ترخيص.

الهدف النهائي: **Faithful HD Remaster كامل للأندرويد**، لا مجرد لعبة مشابهة. أولويات المرحلة التالية: تقييم APK على جهاز فعلي، ثم معايرة اللعب بمقاطع EKA2L1 وإكمال الأوضاع والخصوم والموسيقى والرسومات HD.
